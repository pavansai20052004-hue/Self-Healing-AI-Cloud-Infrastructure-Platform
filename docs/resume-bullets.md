# Resume Bullets

- Built AegisCloud, a Java 21 self-healing AIOps platform that detects service anomalies, ranks remediation actions, evaluates tenant guardrails, and generates root-cause reports.
- Designed a dependency-light domain core with SLO burn-rate analysis, counterfactual remediation planning, incident lifecycle management, audit events, and reinforcement-learning-inspired remediation scoring.
- Implemented Spring Boot microservices for monitoring, healing decisions, and incident intelligence, plus a FastAPI prediction service for metric and log classification.
- Added Kubernetes production controls including namespace-scoped RBAC, NetworkPolicy, PodDisruptionBudgets, HorizontalPodAutoscalers, Prometheus alerts, and dry-run remediation commands.
- Created an offline enterprise demo showing detect -> predict -> govern -> simulate -> heal -> audit with tenant policies, blast-radius forecasts, canary steps, and operator approval gates.
